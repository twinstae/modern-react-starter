# TICKET-00012: 주인 확인 — 열쇠 건넴, 서랍 속 책 안내, 산 책 기록

- 스펙: [TECH_SPEC](TECH_SPEC.md) §3.3 주인 확인, §5.3 주인 확인·서랍 속 책 안내, I-9, I-13, I-15, I-16, R-7, PRD UC-06·11
- Blocked by: TICKET-00005, TICKET-00007, TICKET-00009
- Status: done

## 만들 것

- `OwnerCheckScreen`(표시용): TICKET-00005의 주인 view model — 추천 서랍(크게), 2순위 서랍, 비슷함, 각 서랍의 책과 수량, 3종 미만 경고, [이 서랍 열쇠 건넴] / [다른 서랍 건넴].
- `DrawerBooksScreen`(표시용): 건넨 서랍의 책들(제목, 저자, 권하는 이유, 함께 생각해 볼 질문), [처음으로], 주인용 [산 책 기록](작게).
- API(주인 토큰): 열쇠 건넴 기록(세션 ID, 버전, 추천 서랍, 건넨 서랍), 산 책 기록(세션 ID, 버전, 서랍, 책) + 서랍 속 수량 줄이기.
- 라우트: 결과 → PIN → 주인 확인 → 건넴 → 서랍 속 책 안내 → 처음으로(차례를 버린다).

## 알아야 할 것

- 주인이 몇 초 안에 판단하고 열쇠를 건네는 화면이다. 서랍 표시(번호·열쇠)가 가장 크다.
- 주인 확인은 손님 화면과 색·머리말을 달리해 "주인 모드"임이 보이게 한다. 주인 토큰이 끝나면 손님 화면으로 돌아간다.
- 열쇠 건넴과 산 책은 학습 데이터의 정답이다(PRD 부록 A-4). "추천과 다르게 건넴"이 기록에서 드러나야 한다(R-7).
- 서랍 속 책 안내 화면은 손님용이라 건넨 서랍의 책만 보인다(I-9). 다른 서랍 정보는 주인 확인에만 있다(I-15).
- 이 화면들의 이벤트(`drawer_handover`, `book_view`, `purchase_record`, `reset`)를 TICKET-00008의 퍼널에 잇는다.

## 인수 조건

- [x] 주인 확인에서 추천 서랍의 건넴을 누르면 그 서랍으로, 다른 서랍을 고르면 그 서랍으로 `onHandover`(컴포넌트).
- [x] 3종 미만 서랍과 비슷함이 주인 확인에 보인다(컴포넌트).
- [x] 열쇠 건넴 기록에 추천 서랍과 건넨 서랍, 버전이 함께 남는다(api, I-16).
- [x] 산 책을 기록하면 그 서랍 속 수량이 줄어든다(api).
- [x] 서랍 속 책 안내에 건넨 서랍의 책만 보이고, 처음으로를 누르면 `onFinish`(컴포넌트).
- [x] 처음으로 뒤 차례 값에 별명·답·결과가 없다(코어, I-13).
- [x] 스토리: 주인 확인(보통, 비슷함, 3종 미만), 서랍 속 책 안내(책 3권, 수량 0인 책 포함).

## 작업하며 배운 것

- 주인 확인 화면은 `ownerView`가 필요로 하던 `Book`(관련도·핵심 단어 포함) 대신
  `ShelfBook`을 받게 했다. 공개 키오스크 서가에는 관련도가 없으므로, 손님 묶음에서
  바로 view를 만들 수 있고 가짜 관련도를 채우지 않아도 된다. `Book`은 그대로
  `ShelfBook`을 만족한다.
- 열쇠 건넴과 산 책은 "추천"과 "실제"가 다른 데이터다. 그래서 기록 테이블에
  `recommended`와 `handed`를 함께 넣고, 산 책 수량은 서랍 저장소에서 원자적으로
  줄였다(`decrease`). 읽고-고치는 두 단계를 거치지 않아 동시에 기록해도 0 아래로
  내려가지 않는다(R-9).
- 산 책 기록이 학습 데이터의 정답이므로, 서랍에 그 책 줄이 없어도 기록은 남기고
  수량만 0으로 답하게 했다. 기록을 잃는 것보다 수량이 참고값으로 어긋나는 편이 낫다.
- 주인 토큰은 라우트 메모리에만 두고 만료 타이머로 상태를 닫았다. 주인 모드에서는
  손님의 90/120초 유휴 타이머를 멈추되, 토큰 만료가 쓰기 동작의 안전장치다. 건넨
  뒤에는 화면을 유지하고 산 책 기록만 막는다.
- `drawerBooksView`는 손님 경계라 `bookId`를 넣지 않았다. 화면이 산 책을 기록하려면
  id가 필요해, 같은 서랍 속 책 순서에서 나온 공개 서가 목록과 index로만 맞춰
  `DrawerBooksScreenBook`을 만들었다. 다른 서랍 정보는 이 경계를 넘지 않는다(I-9).
