# TICKET-00014: 서버 없이 태블릿 안에서만 도는 PWA

- 스펙: [ADR 0006](adr/0006-local-first-indexeddb-pwa.md), TECH_SPEC I-11·I-12·I-15·I-16
- Status: in progress

## 만들 것

- IndexedDB 저장소 다섯 개. 메모리 구현과 같은 계약 테스트를 통과한다.
- PIN·운영 비밀번호 해시를 Web Crypto로. 주인 토큰을 없앤다.
- 운영 비밀번호: 처음 열 때 정하고, 다음부터 그 비밀번호로 운영 화면을 연다.
- 라우트가 HTTP 대신 기기 저장소 위의 유스케이스를 부른다. 빈 기기는 시드 서랍을 공개한다.
- 운영 화면 **기록** 탭: 이벤트·열쇠 건넴 내려받기, 서랍 내보내기·가져오기.
- 서버·DB·better-auth·마이그레이션·시드 스크립트와 그 의존성을 지운다. 정적 SPA로 빌드한다.
- PWA: 매니페스트, 아이콘, 서비스 워커(모든 빌드 파일 미리 캐시), 글꼴 오프라인.

## 인수 조건

- [ ] IndexedDB 서랍·공개 버전·이벤트·열쇠 건넴·주인 잠금 저장소가 메모리와 같은 계약을 통과한다.
- [ ] 다시 연 DB에서도 앞서 저장한 값이 그대로 나온다.
- [ ] PIN·비밀번호는 해시로만 저장되고, 맞는 값만 통과한다. 5번 틀리면 60초 잠긴다.
- [ ] 운영 비밀번호가 없으면 정하는 화면, 있으면 들어가는 화면이 나온다.
- [ ] 빈 기기를 처음 열면 시드 서랍과 공개 버전 1이 생기고, 다시 열어도 또 만들지 않는다.
- [ ] 내려받은 기록에 별명이 없고, 모든 행에 버전이 있다(I-12·I-16).
- [ ] 내보낸 서랍을 가져오면 같은 서랍·문항·책이 된다. 틀린 파일은 아무것도 바꾸지 않는다.
- [ ] `server/`, elysia, better-auth, drizzle, PGlite, postgres, nitro가 앱에서 사라진다.
- [ ] `bun run build`가 정적 파일과 서비스 워커를 낸다.
