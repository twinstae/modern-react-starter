# 손님 차례의 계산은 브라우저의 순수 코어로 하고, 별명은 서버로 보내지 않는다

별명, 답, 채점, 순위, 상태 문장은 손님 탭의 메모리에서 순수 함수로 계산한다. 서버는 공개 버전 묶음과
서랍 속 책의 공개 필드만 내려 주고, 답을 계산해 주지 않는다. 공개 점검은 서버에서 같은 코어를 돌린다.

## Consequences

- 와이파이가 흔들려도 손님 차례는 끝까지 간다(EX-11). 이벤트는 큐에 쌓아 나중에 보낸다.
- 별명이 요청·이벤트·저장소로 새지 않는다(I-12). 이벤트 스키마에는 별명 자리가 아예 없다.
- 손님 화면에 점수·서랍 코드·다른 서랍의 책이 들어가지 않도록 view model 타입으로 막는다(I-9).
