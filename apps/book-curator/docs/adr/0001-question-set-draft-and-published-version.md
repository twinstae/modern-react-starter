# 질문 세트는 초안과 불변 공개 버전으로 나누고, 본문을 JSON 문서로 저장한다

질문 세트는 문항·서랍 정의·채점 방식·문장 템플릿을 통째로 읽고 통째로 쓴다. 행 단위 질의가 필요 없고,
공개된 뒤에는 고치지 않고 새 버전을 만들어야 한다(I-11). 그래서 초안은 행 하나의 본문 jsonb로,
공개 버전은 버전 번호가 붙은 불변 행으로 둔다.

## Consequences

- 공개 중 포인터가 지금 손님에게 보이는 버전 하나를 가리킨다. 손님 차례는 시작할 때 받은 버전을 끝까지 쓴다.
- 채점 방식과 학습 모델도 같은 본문 안에 들어간다. 스키마를 고치지 않고 새 버전을 만든다.
- 질문 세트를 조회하는 코드는 초안과 공개 버전을 구분해 읽는다. 공개 버전 행은 고치지 않는다.
