# 운영자 인증은 better-auth, 태블릿의 주인 확인은 PIN 잠금 + 짧은 토큰 [확인 필요]

큐레이터·관리자·주인은 MVP에서 한 운영자 역할이다. 운영 화면 로그인은 qr-quest와 같이 better-auth를
주입해 처리한다. 같은 태블릿에서 손님이 주인 확인을 열 때는 별도 계정 대신 PIN을 풀고 짧은 주인 토큰을
받아 열쇠 건넴과 산 책 기록을 남긴다.

## Considered Options

- 주인이 자기 휴대폰에서 여는 안(PRD 열린 질문 4)도 있다. 현장에서 PIN이 번거로우면 그쪽으로 바꾼다.

## Consequences

- PIN 해시와 짧은 토큰의 수명·실패 횟수 제한은 TICKET-00009에서 정한다.
- 주인 확인이 잠겨 있지 않으면 손님이 다른 서랍의 정보를 볼 수 있다. 잠금과 화면 분리를 테스트로 지킨다(I-15).
- 이 결정은 아직 확인이 필요하다. 정해지기 전에는 인증을 주입 가능한 포트로 두어 교체 비용을 낮춘다.
