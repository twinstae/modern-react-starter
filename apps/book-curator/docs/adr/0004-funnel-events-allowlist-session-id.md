# 퍼널 이벤트와 정답 표시는 허용 목록 스키마로만 받고, 차례마다 새 세션 ID로 묶는다

이벤트와 정답 표시는 학습과 운영의 근거가 되지만, 공용 태블릿에서 나오는 익명 기록이다. 받는 필드를
허용 목록으로 고정한 엄격 객체로 두고, 모르는 필드가 오면 거부한다. 한 차례는 탭 메모리에서 새로 만든
세션 ID로만 묶고, 그 값은 사람과 연결되지 않는다.

## Consequences

- 별명, 이름, 연락처, IP, User-Agent가 저장될 자리가 스키마에 없다(I-12).
- 이벤트 요청에 임의 필드를 더해도 저장 행은 허용 목록 열뿐이다. API 테스트와 속성 테스트가 확인한다.
- 정답 표시에는 어느 버전으로 답했는지가 함께 남는다(I-16). 나중에 학습 데이터로 내보낼 수 있다.
