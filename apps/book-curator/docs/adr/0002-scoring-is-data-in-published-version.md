# 채점 방식은 공개 버전 안의 데이터다

답을 서랍 점수로 바꾸는 방법을 코드 분기로 두지 않고 공개 버전 안의 데이터로 둔다. v1은 서랍별 문항 평균
(`item-mean`), v2는 학습 모델(`learned`)이 같은 자리에 들어간다. 순위·문장·화면·이벤트는 점수 뒤에서
채점 방식을 모른다.

## Consequences

- 채점 방식이 바뀌어도 공개 버전만 새로 만들면 되고, 손님 차례와 화면은 그대로다.
- 모든 채점 방식이 같은 `DrawerScores` 모양을 내야 한다. 타입과 속성 테스트가 이를 지킨다(I-6).
- 학습 모델도 버전에 담긴 불변 데이터다. 같은 버전과 같은 답이면 같은 결과가 나온다(I-2).
