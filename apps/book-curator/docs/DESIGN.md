# 화면과 문구의 기준

책방79-1의 실제 가게 사진과 인스타그램, 그리고 아래 레퍼런스를 보고 정했다.
화면을 고칠 때 이 문서를 먼저 읽고, 취향만으로 색·문구를 바꾸지 않는다.

## 1. 가게에서 가져온 것

- **초록 간판** `BOOK SHOP 79-1` — 차분한 딥그린. 화면의 주 버튼과 작은 라벨.
- **노란 벽과 꽃** — 브랜드의 노랑. 화면 전체를 덮지 않고, 위쪽 띠와 선택 상태에만.
- **나무 선반, 종이, 손바느질** — 종이 오프화이트와 2px 검정 테두리, 낮은 모서리.
- **빨간 재봉틀, 스탬프, 손글씨** — 서랍 표시·경고 같은 작은 강조에만 쓰는 빨강.
- **책 표지의 색** — 화면은 책 표지를 흉내 내지 않는다. 색은 초록·노랑·빨강 세 가지로 제한한다.

## 2. 레퍼런스

- [토스의 8가지 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss):
  Clear, Concise, Casual, Respect, Emotional. 특히 **Weed cutting**(의미 없는 단어),
  **Remove empty sentences**(같은 말 반복), **Easy to speak**(소리 내어 읽어 어색하지 않은 문장),
  **Suggest over force**(강요하지 않기). 이 앱의 문구는 이 기준으로 다시 썼다.
- [Warm editorial 스타일](https://pageproofer.com/inspiration/warm-editorial/):
  따뜻한 오프화이트 종이, 큰 세리프, 색은 하나의 액센트로 아껴 쓴다. 다만 이 앱은
  노랑·초록·빨강을 가게의 실제 색으로 쓰되, 면적을 제한한다.
- [NN/G 터치 타깃](https://www.nngroup.com/articles/touch-target-size/):
  손가락 타깃은 1cm 이상, 주요 버튼은 그보다 크게. 태블릿에서 서서 누르는 화면이다.
- 책방79-1의 인스타그램·가게 사진: 초록 간판, 노란 벽, 나무, 손으로 만든 물건, 책 표지.
  “책, 낯설게 만나기”의 말투. 전시장 같은 흰 화면보다, 누군가 손으로 만든 가게의 온도.

## 3. 색

| 역할    | 값                    | 쓰는 곳                                          |
| ------- | --------------------- | ------------------------------------------------ |
| canvas  | `#fbf9f4`             | 화면 바탕. 노란 크림이 아니라 **따뜻한 흰 종이** |
| surface | `#fffefa`             | 카드, 입력칸                                     |
| ink     | `#18231d`             | 본문, 테두리, 큰 제목                            |
| pine    | `#1f5a45` / `#174634` | 주 버튼, 작은 라벨, 포커스                       |
| yellow  | `#f2c94c` / `#fbeab8` | 화면 위 8px 띠, 선택 상태, 인용 옆 선            |
| seal    | `#c4473a`             | 서랍 표시, 경고, 오류. 면적으로 크게 쓰지 않는다 |

- 배경을 노랑으로 채우지 않는다. 노랑은 **띠·선·선택 상태**에만 둔다.
- 갈색·베이지로 전체를 덮지 않는다. 이전 화면이 “누리끼리” 보인 원인이다.
- 한 화면에 강조색은 하나. 주 행동은 초록 버튼, 서랍 표시만 빨강.

## 4. 글자

- 제목·결과 문장·큐레이터의 이유: **Noto Serif KR** (명조). 문장이 주인공인 곳.
- 질문·버튼·라벨·입력: **Noto Sans KR** (고딕). 읽고 누르는 곳.
- 결과 첫 문장 `clamp(2rem, 3.4vw, 3rem)`, 질문 `clamp(1.75rem, 3vw, 2.5rem)`.
- 본문 1.25rem, 캡션 1rem. 태블릿 세로·가로에서 줄 길이를 20~24자로 제한한다.
- 결과 문장은 `word-break: keep-all`로 한국어 어절을 붙여 읽는다.

## 5. 문구

- **소리 내어 읽는다.** “~상태입니다”, “~이어집니다”, “~에 그렇다고 답하신” 같은
  번역투·행정 문어체를 쓰지 않는다.
- **한 문장에 한 메시지.** 2순위는 “함께 보면 좋은 책”처럼 짧게.
- **사용자를 규정하지 않는다.** “당신은 ○○형”이 아니라 “지금은 ○○이 필요해 보여요”.
- **과장하지 않는다.** 별명은 저장하지 않지만 답은 익명 이벤트로 남는다. 그래서
  “기록은 남지 않아요” 대신 “별명은 저장하지 않아요”라고 쓴다.
- **다음 행동을 알려 준다.** 결과에서는 “이 화면을 책방 주인에게 보여 주세요”,
  질문에서는 “← 이전 질문”.
- 시드의 가정 문구는 `OPEN-QUESTIONS.md`·`SEED-QUESTIONS.md`에만 표시하고,
  손님에게 보이는 데이터에는 `[가정]` 같은 편집 표시를 넣지 않는다.

## 6. 화면별 사용자 관점

- **별명**: 서서 처음 만나는 화면. 3초 안에 “무엇을 하는 곳인지”와 “무엇을 누르면 되는지”가
  보여야 한다. 입력과 시작 버튼은 한 카드 안에 두고, 화면 가운데에 둔다. 위아래로
  크게 벌려 빈 공간을 만들지 않는다.
- **질문**: 14문항을 3분 안에 지나간다. 질문 하나와 다섯 칸만. 카드 다섯 개는 손가락
  마디 크기(높이 6rem 이상)로, 숫자와 말을 함께 보여 준다. 작은 동그라미 라디오만
  크게 늘어놓지 않는다. 누르면 바로 다음 질문.
- **결과**: 뒤에 다음 손님이 있을 수 있다. 첫 문장은 2~3줄 안에 끝내고, 두 번째 문장은
  작게. 카드는 종이 한 장처럼 보이게. 서랍 표시는 멀리서도 읽히게. 점수·코드·책 제목은
  어디에도 없다. 주인 확인 버튼은 한눈에 보이는 주 행동.

## 7. 레이아웃 불변식

- `height: 100dvh` + `overflow: hidden`으로 내용을 가두지 않는다. `min-height`를 쓰고,
  내용이 길면 화면이 자연스럽게 늘어나게 한다. 겹침은 장식이 아니라 버그다.
- 세로 834×1112, 가로 1112×834에서 결과·질문·별명 화면을 **스크린샷으로** 확인한다.
  텍스트 상자끼리 겹치지 않고, 가로에서 카드와 버튼이 충돌하지 않아야 한다.
- 결과 화면은 `lg`에서 카드와 행동을 2단, 세로에서는 1단. 질문 화면은 다섯 칸을
  한 줄에 두되, 320px대에서는 가로 스크롤 대신 두 줄로 접는 안을 검토한다.
- 터치 타깃은 최소 3rem, 주요 버튼은 3.5rem 이상.
- 고객 화면(질문·결과·서랍 속 책)은 태블릿 세로·가로에서 스크롤 없이 맞춘다.
  주인 확인만 7서랍을 모두 펼치면 세로 스크롤을 허용하고, 추천·2순위를 먼저 보인다.
  나머지 서랍의 책은 접기로 두어 주인이 먼저 열쇠를 고르게 한다.

## 8. 아직 정할 것

- 실제 가게 사진을 화면 배경이나 카드에 쓸지, 지금처럼 색·활자만 쓸지.
- 서랍 표시를 손님에게 어디까지 보일지(번호만/열쇠 번호 포함).
- 다섯 칸의 2~4에 “아니다/보통/그렇다”를 항상 보일지, 양 끝만 글자로 둘지.
- 노란 띠를 모든 화면에 둘지, 결과 화면에만 둘지.
