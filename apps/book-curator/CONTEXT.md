# BOOK CURATOR

책방79-1에 비치된 태블릿에서 손님이 질문에 답하고, 서랍 두 개의 상태와 추천 서랍을 받아
주인에게 열쇠를 받는 앱이다. 결과는 책 제목이 아니라 서랍과 큐레이터의 문장으로 말한다.

## 서랍과 질문

**서랍** (`Drawer`):
결과 하나이자 책이 담긴 실제 서랍. 코드, 이름, 핵심 단어, 상태 문장, 서랍 표시(번호·열쇠)를 가진다.
_Avoid_: 결과 유형, 성향, ○○형

**서랍 코드** (`DrawerCode`):
B1~B7. 질문 세트와 서가가 서로를 가리키는 유일한 값이며 **이용자에게 보이지 않는다**.
_Avoid_: 색, 이름

**질문 세트** (`QuestionSet`):
서랍 정의, 질문, 채점 방식, 문장 템플릿, 기준 응답을 묶은 설계. 초안이거나 공개 버전이다.
_Avoid_: 설문, 테스트

**공개 버전** (`PublishedVersion`):
공개되며 얼어붙은 질문 세트. 한 번에 하나만 "공개 중"이고, 손님 차례는 시작할 때 받은 버전으로 끝난다.
_Avoid_: 릴리스

**질문** (`Question`):
한 화면의 물음 하나. 문항형이거나 선택형이다.
_Avoid_: 문항(문항형만 가리킬 때가 아니면)

**문항** (`Item`):
"○○한가요?" 문장 하나. 한 서랍에 속하고, 반대로 읽을 수 있다.
_Avoid_: 질문, 항목

**답** (`Answer`):
문항형이면 1~5, 선택형이면 선택지 id. 손님 차례의 메모리에만 둔다.
_Avoid_: 응답(이벤트와 헷갈림)

**채점 방식** (`Scoring`):
답을 서랍 점수로 바꾸는 방법. `item-mean`, `choice-weight`, `learned`가 있고 공개 버전 안의 데이터다.
_Avoid_: 알고리즘(넓을 때만)

**서랍 점수** (`DrawerScores`):
서랍별 점수와 그 점수에 기여한 답. 이용자에게 보이지 않는다.
_Avoid_: 결과, 순위

**순위** (`Ranking`):
1순위·2순위 서랍. 동점 규칙으로 늘 하나씩 정하고 "비슷함" 표시를 가질 수 있다.
_Avoid_: 점수, 결과

**상태 문장** (`Statement`):
"{별명} 님에게는 지금 {서랍}이 필요한 상태입니다"처럼 서랍을 설명하는 문장.
_Avoid_: 진단, 결과 설명

**인용** (`Citation`):
권하는 이유에 들어가는 이용자의 답(문항 문장 또는 선택지 문장). 실제로 한 답이어야 한다.
_Avoid_: 근거, 코멘트

**추천 서랍** (`RecommendedDrawer`):
1순위 서랍. 주인이 열쇠를 건넬 기본값이다.
_Avoid_: 정답, 결과

## 손님 차례

**별명** (`Nickname`):
손님이 정한 짧은 이름. 화면에서만 쓰고 저장하지 않는다.
_Avoid_: 이름, 닉네임, 사용자

**손님 차례** (`Turn`):
한 손님이 별명을 넣고부터 처음으로 돌아갈 때까지. 별명·답·결과를 탭 메모리에만 둔다.
_Avoid_: 세션(세션 ID와 헷갈림), 로그인

**주인 확인** (`OwnerCheck`):
결과 화면에서 잠금을 풀고 여는 주인용 화면. 건넬 서랍, 서랍 속 책, 기록을 보여 준다.
_Avoid_: 관리자 화면

**열쇠 건넴** (`Handover`):
주인이 실제로 건넨 서랍의 기록. 학습 데이터의 정답이다.
_Avoid_: 결과, 배정

## 서가

**책** (`Book`):
제목, 저자, 서랍별 관련도(0~5, 참고용), 핵심 단어, 권하는 이유, 함께 생각해 볼 질문을 가진다.
_Avoid_: 상품

**서랍 속 책** (`DrawerStock`):
서랍마다 (책, 수량). 팔리면 줄인다.
_Avoid_: 재고(넓을 때만)

**공개 점검** (`SetReport`):
표본 응답과 쌓인 응답으로 계산한 보고. 결정 여부, 쏠림, 기준 응답, 문항 수 균형을 본다.
_Avoid_: 검증 결과

**기준 응답** (`BaselineAnswers`):
"이렇게 답하면 이 순위"로 질문 세트와 함께 저장하는 기대값.
_Avoid_: 테스트 케이스

## 기록과 운영

**퍼널 이벤트** (`FunnelEvent`):
손님이 단계를 지날 때 남는 익명 기록. 허용 목록 필드만 가진다.
_Avoid_: 로그, 트래킹

**세션 ID** (`SessionId`):
손님 차례마다 탭 메모리에서 새로 만드는 무작위 값. 이벤트와 정답 표시를 묶는 유일한 열쇠다.
_Avoid_: 사용자 ID

**태블릿 이름** (`KioskName`):
어느 태블릿인지("계산대 옆"). 사람과 무관하다.
_Avoid_: 기기 ID
