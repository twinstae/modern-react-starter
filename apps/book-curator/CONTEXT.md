# BOOK CURATOR

책방79-1에 비치된 태블릿에서 손님이 질문에 답하고, 서랍 두 개의 상태와 추천 서랍을 받아
주인에게 열쇠를 받는 앱이다. 결과는 책 제목이 아니라 서랍과 큐레이터의 문장으로 말한다.

## 서랍과 질문

**서랍** (`Drawer`):
결과 하나이자 책이 담긴 실제 서랍. 이름, 문항, 서랍에 든 책만 가진다. 운영자가 만들고 고치고 지운다.
_Avoid_: 결과 유형, 성향, ○○형

**서랍 id** (`DrawerId`):
문항·서가·기록이 서랍을 가리키는 값이며 **이용자에게 보이지 않는다**.
_Avoid_: 서랍 코드, 색, 이름

**질문 세트** (`QuestionSet`):
서랍들의 문항을 서랍마다 돌아가며 섞어 묻는 것. 따로 만들지 않고 공개할 때 서랍에서 만든다.
_Avoid_: 설문, 테스트, 초안

**공개 버전** (`PublishedVersion`):
공개하는 순간의 질문 세트와 서랍 속 책을 얼린 것. 가장 최근 버전이 손님에게 나가고, 손님 차례는 시작할 때 받은 버전으로 끝난다.
_Avoid_: 릴리스

**문항** (`Question`):
"○○한가요?" 문장 하나. 한 서랍에 속하고 손님은 1~5로 답한다.
_Avoid_: 항목

**답** (`Answer`):
1(전혀 아니다)~5(매우 그렇다). 손님 차례의 메모리에만 둔다.
_Avoid_: 응답(이벤트와 헷갈림)

**채점 방식** (`Scoring`):
답을 서랍 점수로 바꾸는 방법. 지금은 서랍별 문항 평균(`item-mean`)뿐이다.
_Avoid_: 알고리즘(넓을 때만)

**서랍 점수** (`DrawerScores`):
서랍별 점수와 그 점수에 기여한 답. 이용자에게 보이지 않는다.
_Avoid_: 결과, 순위

**순위** (`Ranking`):
1순위·2순위 서랍. 동점 규칙으로 늘 하나씩 정하고 "비슷함" 표시를 가질 수 있다.
_Avoid_: 점수, 결과

**상태 문장** (`Statement`):
"{별명} 님에겐 지금, {서랍}이/가 필요해 보여요"처럼 서랍을 설명하는 문장. 문형은 하나로 고정이다.
_Avoid_: 진단, 결과 설명

**인용** (`Citation`):
결과 화면에 들어가는 이용자의 답(문항 문장). 실제로 그렇다고 답한 것이어야 한다.
_Avoid_: 근거, 코멘트

**추천 서랍** (`RecommendedDrawer`):
1순위 서랍. 주인이 열쇠를 건넬 기본값이다.
_Avoid_: 정답, 결과

## 손님 차례

**별명** (`Nickname`):
손님이 정한 짧은 이름. 화면에서만 쓰고 저장하지 않는다.
_Avoid_: 이름, 닉네임, 사용자

**손님 차례** (`Turn`):
한 손님이 별명을 넣고부터 처음으로 돌아갈 때까지. 별명·답·결과를 탭 메모리에만 둔다.
_Avoid_: 세션(세션 ID와 헷갈림), 로그인

**주인 확인** (`OwnerCheck`):
결과 화면에서 잠금을 풀고 여는 주인용 화면. 건넬 서랍과 서랍 속 책을 보여 준다.
_Avoid_: 관리자 화면

**열쇠 건넴** (`Handover`):
주인이 실제로 건넨 서랍의 기록. 학습 데이터의 정답이다.
_Avoid_: 결과, 배정

## 서가

**책** (`DrawerBook`):
제목, 저자, 출판사. 무슨 책인지 알아볼 만큼만 가지고, 한 서랍에만 든다. 수량은 세지 않는다. 운영자는 CSV로 올린다.
_Avoid_: 상품, 재고

**공개 점검** (`PublishCheck`):
공개 전 자동 점검. 서랍 2개 미만·문항 없는 서랍은 막고, 쏠림·문항 수 차이·책 3권 미만은 경고한다.
_Avoid_: 검증 결과

## 기록과 운영

**퍼널 이벤트** (`FunnelEvent`):
손님이 단계를 지날 때 남는 익명 기록. 허용 목록 필드만 가진다.
_Avoid_: 로그, 트래킹

**세션 ID** (`SessionId`):
손님 차례마다 탭 메모리에서 새로 만드는 무작위 값. 이벤트와 정답 표시를 묶는 유일한 열쇠다.
_Avoid_: 사용자 ID

**태블릿 이름** (`KioskName`):
어느 태블릿인지("계산대 옆"). 사람과 무관하다.
_Avoid_: 기기 ID
