# SOLO QUEST

혼자 하는 TRPG에서 마스터와 플레이어의 대화, 주사위 판정을 하나의 시간순 기록으로 남기는 앱이다.

## 기록

**세션**:
한 번의 플레이 단위. 하나의 이벤트 로그를 가지며, 시작할 때 넘겨받은 상태 위에서 진행된다.
_Avoid_: 게임, 방, 채팅방

**이벤트**:
세션에서 이미 일어나 확정된 사실 하나. 한번 기록되면 바뀌거나 지워지지 않는다.
_Avoid_: 액션, 메시지(대화만 가리킬 때가 아니면), 로그 항목

**이벤트 로그**:
한 세션의 이벤트를 일어난 순서대로 늘어놓은 것. 화면의 기록은 이벤트 로그 자체를 보여 준다.
_Avoid_: 히스토리, 채팅 기록

**세션 상태**:
이벤트 로그를 차례로 적용해 얻는 현재 상태. 지금은 캐릭터와 매크로 목록이며, 다음 세션이 넘겨받는 유일한 것이다(매크로를 넘겨받는 것은 아직 정하지 않았다). 대화와 판정은 세션 상태를 바꾸지 않는다.
_Avoid_: 스냅샷(넘겨받는 순간을 가리킬 때가 아니면), 게임 상태

**넘겨받은 상태**:
세션이 시작할 때 받는 세션 상태. 이전 세션의 마지막 세션 상태이거나, 처음이면 기본 캐릭터만 있는 상태다. 이벤트 로그는 넘겨받지 않는다.
_Avoid_: 세이브, 이어하기 데이터

**세션 목록**:
만들어진 세션들의 제목과 만든 시각. 이벤트 로그와 따로 관리된다.

## 대화와 판정

**편**:
기록이 마스터 쪽에서 나왔는지 플레이어 쪽에서 나왔는지의 구분. 마스터 편은 세계의 묘사와 NPC를, 플레이어 편은 주인공 쪽을 맡는다.
_Avoid_: 역할, 진영, 사이드

**마스터**:
세계를 묘사하고 반응하는 편. 사람이 직접 친다.
_Avoid_: GM(기본 캐릭터 이름과 헷갈림), 세계, 진행자

**플레이어**:
주인공 쪽 행동과 말을 하는 편.

**대화**:
한 편이 한 화자로 남긴 140자 이하의 일반 텍스트 기록.
_Avoid_: 채팅, 메시지

**판정**:
주사위를 굴려 확정된 결과의 기록. 표기, 주사위별 값, 합계, 선택적 라벨을 가진다. 다시 굴리지 않는다.
_Avoid_: 굴림(굴리는 행위를 가리킬 때가 아니면), 체크, 롤

**표기**:
굴릴 주사위를 적는 식. `NdM`과 상수를 더하고 뺀 것이다. `NdF`(Fate 주사위)도 쓸 수 있고, 비교 판정이면 비교 연산자와 목표가 붙는다. 예: `2d6+1`, `d100`, `4dF+3`, `d6+2 max10 > 2d10`, `3d6 <= 12`
_Avoid_: 주사위 식, 공식

**비교 판정**:
**액션 점수**를 **목표**와 견주는 판정. 표기가 비교 연산자(`>`, `>=`, `<`, `<=`)를 가진다.
예: Ironsworn `d6+2+1 max10 > 2d10`, Cypher `d20 >= 9`, 겁스 `3d6 <= 12`, Fate `4dF+3 >= 2`
_Avoid_: 대결, 도전 판정(도전 주사위와 헷갈림)

**Fate 주사위**:
-1, 0, +1이 나오는 주사위. `NdF`로 적는다.

**액션 점수**:
비교 연산자 왼쪽(비교가 없으면 표기 전체)을 더한 값. `max<N>`이 있으면 N을 넘지 않는다.

**목표**:
비교 연산자 오른쪽. **도전 주사위**이거나 **목표치**다.

**도전 주사위**:
목표가 주사위인 것. 더하지 않고 하나씩 액션 점수와 견주어 이긴 개수를 센다.

**목표치**:
목표가 정수인 것. `3*3`처럼 곱으로 적을 수 있다.

**차이**:
액션 점수와 목표치의 차이. 이기는 쪽이 +다. `>`, `>=`는 점수 − 목표치, `<`, `<=`는 목표치 − 점수다.

**결과 값**:
결과 이름을 정하는 값 하나. 도전 주사위면 이긴 개수, 목표치면 차이, 비교가 없으면 액션 점수다.

**눈**:
액션 쪽 주사위만 더한 값(상수 제외). 예: `d20+2`에서 d20이 20이면 눈은 20이다.

**Match**:
도전 주사위가 둘 이상이고 모두 같은 값인 것.

**매크로**:
이름을 붙여 등록한 판정 표기의 틀. **빈칸**, **결과 이름**, **눈 효과**를 가질 수 있다. 세션 상태다.
예: `2d6+{능력치:-1..3} => ..6 실패 | 7..9 약한 성공 | 10.. 강한 성공`
_Avoid_: 단축키, 프리셋

**빈칸**:
매크로를 굴릴 때 고르는 정수. `{이름:최소..최대}`로 적는다. 음수도 된다.
_Avoid_: 변수, 인자

**결과 이름**:
결과 값의 범위마다 붙인 이름. 예: `..6 실패 | 7..9 약한 성공 | 10.. 강한 성공`

**눈 효과**:
눈의 범위마다 붙인 이름. 결과 이름 옆에 붙고, `!`를 붙이면 결과 이름을 바꾼다. 예: Cypher `20 큰 이득`, 겁스 `18 !대실패`

**라벨**:
판정이 무엇을 위한 것인지 적는 짧은 글. 예: "자물쇠 따기"

**짧은 글**:
앞뒤 공백을 뺀 1~140자의 글. 세션 제목, 대화, 라벨, 캐릭터 이름이 모두 따른다.

## 오라클

**오라클**:
주사위를 한 번 굴려 무작위 결과를 얻는 표. 눈이 드는 칸이나 구간의 글이 결과다(`| 53–54 | 절벽 |`).
세션에 묶이지 않고 어느 세션에서나 찾아 쓴다. 세션 상태가 아니므로 다른 세션에서도 같은 표를 본다.
_Avoid_: 표, 랜덤 표, 테이블

**분류**:
오라클을 묶는 가장 큰 단위. 지금은 `철의 맹세` 하나다.
_Avoid_: 카테고리, 장르, 세트

**묶음**:
분류 안의 작은 묶음. `일반`, `장소`, `인물`, `기타`. 무엇을 만들 때 쓰는 표인지로 나눈다.
_Avoid_: 그룹, 태그

**한 칸씩 표**:
눈마다 결과가 하나씩 대응하는 표. 새 오라클은 주사위에 맞춰 1번부터 차례대로 칸이 있는 이 모양으로 시작한다.
_Avoid_: 기본 표, 단일 표

**구간 표**:
눈이 드는 구간마다 결과가 있는 표. `1–20 성가신 | 21–55 위험한`. 두 방식 모두 표는 1부터 주사위 면까지 덮는다.
_Avoid_: 범위 표, 구간식

**붙여넣기**:
표를 CSV로 통째로 넣고 빼는 길. 한 줄에 하나씩 `53-54, 절벽`(구간) 또는 `절벽`(한 칸씩, 차례대로),
한 칸씩은 `53, 절벽`처럼 자리를 정해 적을 수도 있다. `00`은 d100에서 100이다.
_Avoid_: 업로드, 불러오기

**오라클 관리 페이지**:
오라클을 더하고 고치고 지우는 페이지(`/oracles`). 왼쪽에서 분류·묶음별로 고르고 오른쪽에서 상세와 편집을 본다.
세션 중에 할 일이 아니다.
_Avoid_: 오라클 편집기, 설정

**설명**:
결과 밑에 회색 글씨로 붙는 짧은 글. 결과만으로는 뜻이 서지 않을 때 쓴다(`최적의 도구` 밑에 "도구를 쓸 때 보탬 두 개를 더 얻습니다").
_Avoid_: 부제, 요약(오라클 자체의 설명과 헷갈림)

**링크**:
결과에서 바로 건너갈 바깥 주소. `http://`나 `https://`로 시작하는 절대 주소만 쓴다.
굴린 기록은 그때의 설명과 링크를 그대로 남기므로, 표를 고치거나 지워도 지난 기록은 그대로다.
_Avoid_: 참고, 출처

**시드 버전**:
시드 표가 바뀔 때마다 올리는 수. 저장된 파일이 이보다 낮으면 아직 없는 시드만 더하고, 지운 표는 되살리지 않는다.
_Avoid_: 데이터 버전, 마이그레이션

**주사위 면**:
오라클을 굴릴 때 쓰는 주사위의 면 수. 기본은 100이고 10, 20, 6도 쓴다. 표는 1부터 이 수까지 빈틈이나 겹침 없이 덮는다.

**오라클 매크로**:
자주 쓰는 오라클을 세션마다 입력창 버튼으로 등록한 것. 표 자체는 전역 오라클을 id로 가리키고, 이 등록만 세션 상태다.
_Avoid_: 오라클 단축키, 즐겨찾기

**오라클 굴림**:
오라클을 굴려 나온 눈과 결과, 굴린 표의 이름을 남긴 판정이다. 이벤트는 `session:oracle_rolled`이고 다시 굴리지 않는다.
_Avoid_: 랜덤 결과

## 캐릭터

**캐릭터**:
기록에서 말하거나 판정하는 존재. 지금은 이름만 가진다. 어느 편에도 묶이지 않는다.
_Avoid_: 인물, PC/NPC(편과 헷갈림), 시트

**화자**:
대화나 판정을 남긴 캐릭터.
_Avoid_: 발화자, 작성자

**기본 캐릭터**:
세션이 시작될 때 항상 있는 `GM`과 `Player`. 보관할 수 없어서, 말할 캐릭터가 하나도 없는 상태가 생기지 않는다.

**보관**:
캐릭터를 더 이상 화자로 고를 수 없게 하는 것. 지난 기록에서는 이름이 그대로 보인다. 캐릭터는 지워지지 않는다.
_Avoid_: 삭제, 비활성화

## 저장

**저장 중**:
제출해서 화면에는 이미 보이지만 아직 로그에 저장되지 않은 이벤트의 상태. 저장되면 사라진다.

**실패**:
저장하지 못한 이벤트의 상태. 화면에는 남지만 로그에는 없으므로 새로고침하면 사라진다. 자동으로 다시 저장하지 않는다.
앞의 이벤트가 실패하면 그 뒤에 기다리던 이벤트도 버전이 이어지지 않아 저장하지 않고 실패로 둔다.
실패한 뒤의 첫 제출은 서버의 로그를 다시 불러온 위에서 받으며, 이때 실패한 이벤트는 화면에서도 사라진다.

**충돌**:
다른 탭이 먼저 기록해 저장하려던 버전이 어긋난 것. 최신 로그를 다시 불러오고 저장을 기다리던 제출은 모두 버린다. 버려진 제출의 글은 해당 편의 입력창에 돌아온다(입력창이 비어 있을 때만).
_Avoid_: 오류(실패와 헷갈림)
충돌 알림은 페이지에 한 곳으로 뜨고 다음 제출을 받으면 사라진다. 다시 불러오기마저 실패하면 기다리던 이벤트를 실패로 두고, 다음 제출이 다시 불러온다.
