# TICKET-00010: 판정 매크로

- 스펙: 없음. 2026-10-17 대화에서 합의
- Blocked by: TICKET-00009
- Status: ready-for-agent

## 만들 것

자주 쓰는 판정을 **매크로**로 등록하고, 입력창 위의 버튼으로 굴린다.
버튼을 누르면 매크로의 **빈칸**(예: 능력치, 수정치, 난이도)마다 고르는 칸이 있는 폼이 뜨고, 제출하면 빈칸을 채운 표기로 그 입력창의 편과 화자로 굴린다.

## 알아야 할 것

- **매크로 식:** `<표기 틀>[ => <결과 0> | <결과 1> | ...][ ; <눈> <이름>, ...]`
  - Ironsworn: `d6+{능력치:1-4}+{수정치:0-4} max10 > 2d10 => 실패 | 약한 성공 | 강한 성공`
  - Cypher: `d20 >= {난이도:0-10}*3 => 실패 | 성공 ; 20 큰 이득, 19 작은 이득, 1 마스터 개입`
  - 표기 틀은 판정 표기(TICKET-00009)에 빈칸 `{이름:최소-최대}`를 넣은 것이다. 최소와 최대는 0 이상의 정수이고, 그 사이 정수를 고른다.
    빈칸 이름은 매크로 안에서 겹치지 않는다.
  - `=>` 뒤는 이긴 개수 0개부터 차례로 적은 **결과 이름**이다. 비교 판정에만 쓸 수 있고, 개수는 도전 주사위 수 + 1(목표치면 2)이다.
  - `;` 뒤는 **눈 효과**다. 액션 쪽 주사위가 하나일 때만 쓸 수 있고, 눈은 그 주사위 면 안의 값이며 겹치지 않는다.
  - `/r`에서는 표기 뒤의 글이 라벨이라 띄어 쓴 이름과 가를 수 없으므로, 결과 이름과 눈 효과는 매크로에만 있다.
  - 등록할 때 빈칸을 모두 최솟값으로, 모두 최댓값으로 채운 표기가 올바른지 확인한다.
  - Cypher의 노력, 자산, 기술은 매크로에 넣지 않는다. 난이도를 고를 때 말로 처리한다.
- **세션 상태:** 매크로는 캐릭터처럼 세션 상태다. `{ id, name, definition }`
  - 이벤트: `session:macro_added { macroId, name, definition }`, `session:macro_removed { macroId }`
  - 이름은 짧은 글이고 매크로끼리 겹치지 않는다. 식이 올바르지 않으면 규칙 위반이다.
  - 넘겨받은 상태는 아직 기본 캐릭터만 넘긴다. 다음 세션이 매크로를 넘겨받는 것은 세션 이어 하기 때 정한다.
- **굴림:** 컨트롤러 `rollMacro({ side, as, macroId, values, label? })`
  - 기록되는 표기는 빈칸을 채운 표기(`d6+2+1 max10 > 2d10`, `d20 >= 3*3`)다. 라벨을 비우면 매크로 이름이 라벨이다.
  - 결과 이름과 눈 효과가 있으면 굴린 결과에 맞는 이름을 `check.outcome`, `check.effect`(비교가 없으면 `effect`만)에 남긴다.
    나중에 매크로를 지워도 기록은 그대로다.
- **화면**
  - 헤더의 매크로 패널(캐릭터 패널과 같은 형식): 목록, 삭제, 이름과 매크로 식으로 등록
  - 입력창마다 매크로 버튼. 누르면 Popover에 빈칸마다 Select, 라벨, "굴리기"가 있다. 화자는 입력창에서 고른 화자다.
  - 매크로 폼은 입력창 폼 안(React 트리)에 Portal로 뜬다. React 이벤트는 Portal을 지나 바깥 폼까지 올라가므로,
    `SimpleForm`이 제출 이벤트 전파를 멈춰 안쪽 폼 제출이 바깥 폼을 제출하지 않게 한다(`@repo/ui` 쪽 고침).

## 인수 조건

- [ ] `parseMacro`가 빈칸, 결과 이름, 눈 효과를 읽고, 잘못된 식(닫히지 않은 빈칸, 겹치는 이름, 최소 > 최대, 채워도 틀린 표기, 결과 개수 불일치, 비교 없는 결과, 주사위가 여럿인 눈 효과, 면 밖의 눈)은 오류다.
- [ ] 빈칸을 채우면 표기가 된다.
- [ ] 세션이 매크로를 더하고 지운다. 같은 이름, 잘못된 식은 규칙 위반이다.
- [ ] 컨트롤러 `rollMacro`가 채운 표기, 라벨(없으면 매크로 이름), 결과 이름, 눈 효과로 판정을 남긴다.
- [ ] 로그에 결과 이름과 눈 효과가 보인다.
- [ ] `SimpleForm` 안 Portal의 `SimpleForm`을 제출해도 바깥 폼은 제출되지 않는다(`@repo/ui` 테스트).
- [ ] 매크로 패널에서 등록하고 지울 수 있다(컴포넌트 테스트).
- [ ] 입력창의 매크로 버튼으로 빈칸을 고르고 굴리면 `{ side, as, macroId, values, label }`이 넘어간다(컴포넌트 테스트).
- [ ] 루트 `bun run ci`가 통과한다.
