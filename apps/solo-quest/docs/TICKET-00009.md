## 만들 것

`/r d6+2+1 max10 vs 2d10 마녀의 숲 정찰`처럼 치면 **도전 판정**이 기록된다.
`vs` 왼쪽은 지금 표기 그대로 더해 **액션 점수**가 되고, 오른쪽 **도전 주사위**는 더하지 않고 하나씩 액션 점수와 견준다.
액션 점수가 도전 주사위보다 커야(같으면 짐) 그 주사위를 이긴다. 기록에는 이기고 진 것이 `X O`처럼 보인다.

- 액션 6, 도전 [3, 5] → `O O` (2개 이김, Ironsworn의 강한 성공)
- 액션 6, 도전 [5, 7] → `X O` (1개 이김, 약한 성공)
- 액션 6, 도전 [7, 6] → `X X` (0개, 실패)

## 알아야 할 것

- **문법:** `<액션 표기>[ max<N>] vs <도전 주사위>`
  - 액션 표기는 지금 표기(`NdM`과 상수의 덧셈 뺄셈)다.
  - `max<N>`은 액션 점수의 상한이다. 생략할 수 있고, `vs` 없이는 쓸 수 없다. Ironsworn은 `max10`이다.
  - 도전 주사위는 `NdM` 하나다. 상수나 여러 항은 오류다.
  - `vs`, `max`는 대소문자를 가리지 않는다. 낱말 사이는 공백 하나 이상이다.
- **입력 해석:** `/r` 뒤 첫 토큰이 표기의 시작이다. 뒤따르는 `max<N>` 토큰과 `vs <도전 주사위>` 두 토큰까지 표기에 넣고, 나머지는 라벨이다.
  표기는 공백 하나로 이어 붙인 글(`d6+2+1 max10 vs 2d10`)로 넘긴다.
- **판정 값:** 액션 점수 = min(합계, 상한). 도전 주사위가 둘 이상이고 값이 모두 같으면 **Match**다(Ironsworn에서 결과를 극적으로 만드는 규칙).
- **이벤트:** 새 이벤트를 만들지 않고 `session:dice_rolled`에 선택 필드 `challenge { cap?, sides, values, outcome? }`를 더한다.
  - `terms`, `total`은 액션 쪽(상한 적용 전 합계)이다. 액션 점수, 이긴 개수, Match는 저장하지 않고 같은 순수 함수로 계산한다.
  - `outcome`은 매크로가 붙이는 결과 이름이다(TICKET-00010). 이 티켓에서는 쓰지 않는다.
  - 이전 판정 이벤트는 그대로 유효하다.
- **표시:** `라벨 표기 · [3] + 2 + 1 = 6 vs [3, 5] O O`. 상한에 걸리면 `= 13 → 10`. Match면 "Match" 표시.
  표시는 진 것(X)을 앞에, 이긴 것(O)을 뒤에 둔다.
