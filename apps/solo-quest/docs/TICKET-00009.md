# TICKET-00009: 비교 판정

- 스펙: 없음. 2026-10-17 대화에서 합의(Ironsworn의 행동 판정, Cypher의 과제 판정)

## 만들 것

`/r d6+2+1 max10 > 2d10 마녀의 숲 정찰`이나 `/r d20 >= 9 자물쇠 따기`처럼 치면 **비교 판정**이 기록된다.
비교 연산자 왼쪽은 지금 표기 그대로 더해 **액션 점수**가 되고, 오른쪽 **목표**와 견준다.

- 목표가 **도전 주사위**(`2d10`)면 더하지 않고 하나씩 견주어 이긴 개수를 센다. 기록에는 `X O`처럼 보인다.
  - 액션 6 `>` [3, 5] → `O O`, [5, 7] → `X O`, [7, 6] → `X X`
- 목표가 **목표치**(`9`, `3*3`)면 이기면 1개, 지면 0개다.
  - `d20 >= 9`에서 9 → `O`, 8 → `X`

## 알아야 할 것

- **문법:** `<액션 표기>[ max<N>][ <비교> <목표>]`
  - 액션 표기는 지금 표기(`NdM`과 상수의 덧셈 뺄셈)다.
  - 비교는 `>`(커야 이김, 같으면 짐)와 `>=`(같아도 이김)다.
  - 목표는 `NdM` 하나이거나, 0 이상의 정수 또는 정수의 곱(`3*3`)이다. 그 밖(`2d10+1`, `d10*2`)은 오류다.
  - `max<N>`은 액션 점수의 상한이다. 생략할 수 있고, 비교 없이는 쓸 수 없다. Ironsworn은 `max10`이다.
  - `max`는 대소문자를 가리지 않는다. 낱말 사이는 공백 하나 이상이다.
- **입력 해석:** `/r` 뒤 첫 토큰이 표기의 시작이다. 뒤따르는 `max<N>` 토큰과 `<비교> <목표>` 두 토큰까지 표기에 넣고, 나머지는 라벨이다.
  표기는 공백 하나로 이어 붙인 글(`d6+2+1 max10 > 2d10`)로 넘긴다.
- **판정 값:** 액션 점수 = min(합계, 상한). 도전 주사위가 둘 이상이고 값이 모두 같으면 **Match**다.
- **이벤트:** 새 이벤트를 만들지 않고 `session:dice_rolled`에 선택 필드 `check { op, cap?, against, outcome?, effect? }`를 더한다.
  - `against`는 `{ type: "dice", sides, values } | { type: "number", value }`다.
  - `terms`, `total`은 액션 쪽(상한 적용 전 합계)이다. 액션 점수, 이긴 개수, Match는 저장하지 않고 같은 순수 함수로 계산한다.
  - `outcome`(결과 이름), `effect`(눈 효과)는 매크로가 붙인다(TICKET-00010). 이 티켓에서는 쓰지 않는다.
  - 이전 판정 이벤트는 그대로 유효하다.
- **표시:** `라벨 표기 · [3] + 2 + 1 = 6 > [3, 5] O O`. 상한에 걸리면 `= 13 → 10`. Match면 "Match" 표시.
  표시는 진 것(X)을 앞에, 이긴 것(O)을 뒤에 둔다.
