# 도메인은 브라우저에서 실행하고, 서버는 이벤트를 검증해 저장만 한다

세션 엔티티, 규칙, 주사위 굴림은 모두 브라우저에서 실행된다. 서버는 받은 이벤트가 스키마에 맞는지와 버전이 끊기지 않는지만 확인하고 저장한다.
비밀 굴림이 없는 혼자 하는 게임이라 서버가 결과를 보증할 이유가 없고, 같은 도메인 코드가 어댑터만 바꿔 오프라인(브라우저 로컬 저장소)에서도 그대로 돌게 하기 위해서다.

## Considered Options

- 서버에서 도메인을 실행해 규칙(예: 보관된 캐릭터로 말하기)까지 검증하는 안도 있었다. 브라우저와 서버가 같은 언어라 가능하지만, 지금은 재생 검증이 필요 없어 하지 않는다.

## Consequences

- 규칙은 브라우저의 mutation만 검사한다. 서버 API를 직접 부르면 규칙을 어긴 이벤트도 스키마만 맞으면 저장된다.
- 이벤트 스키마는 브라우저와 서버가 공유한다.
