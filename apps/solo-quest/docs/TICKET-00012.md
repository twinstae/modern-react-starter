# TICKET-00012: 오라클 관리 페이지

- 스펙: 없음. 2026-10-19 대화에서 합의
- Blocked by: TICKET-00011
- Status: done

TICKET-00011의 화면 부분을 대체한다. 오라클을 고치고 지우는 일은 세션 중에 할 일이 아니므로 세션 패널에서
떼어 내고 따로 관리 페이지로 옮긴다. 표도 하나뿐인 모양에서 **한 칸씩 표와 구간 표**로 나눈다.

## 만들 것

- **분류와 묶음**: 오라클을 큰 분류(`철의 맹세`)와 그 안의 작은 묶음(`일반`, `장소`, `인물`, `기타`)으로 나눈다.
- **한 칸씩 표 / 구간 표**: 주사위 눈에 결과가 하나씩 대응하는 표와, 눈이 드는 구간마다 결과가 있는 표.
  새 오라클은 지금 고른 주사위에 맞춰 1번부터 차례대로 칸이 있는 **한 칸씩 표**로 시작한다.
- **붙여넣기**: 표를 CSV로 붙여넣어 채우고, 지금 표를 다시 CSV로 꺼낸다. 100칸을 손으로 치지 않게 한다.
- **오라클 관리 페이지** (`/oracles`): 왼쪽 사이드바에서 분류·묶음별 목록을 보고, 오른쪽 넓은 자리에서
  상세와 편집을 한다. 세션 패널에는 굴리기와 매크로 등록만 남기고 관리 페이지로 가는 링크를 둔다.

## 알아야 할 것

- **도메인:** `Oracle`에 `category`, `group`, `kind: "single" | "ranges"`가 붙는다.
  - 한 칸씩 표는 눈마다 줄이 하나(`min === max`)여야 한다. `parseOracle`이 어긴 줄을 짚어 준다.
  - 두 방식 모두 표는 1부터 `sides`까지 빈틈이나 겹침 없이 덮는다.
  - `emptyRows(kind, sides)`, `inferKind(rows, sides)`(옛 자료의 방식을 줄 모양으로 알아낸다),
    `rowsByFace(rows, sides)`(눈마다 펼치기), `collapseRanges(rows, sides)`(이웃한 눈이 같은 결과끼리 접기).
    한 칸씩으로 바꿨다가 되돌려도 `collapseRanges(rowsByFace(...))`가 표를 그대로 돌려준다.
  - `parseOracleRows(kind, sides, text)`가 붙여넣은 글을 줄로 읽고, `formatOracleRows(rows, kind)`가 되돌린다.
    구간은 `53-54, 절벽` 또는 `53, 54, 절벽`, 한 칸씩은 `절벽`(차례대로) 또는 `53, 절벽`(자리를 정해).
    `00`은 d100에서 100, `#` 줄과 `d100,결과` 같은 머리글은 건너뛴다.
- **저장:** 분류·묶음·방식이 없던 파일은 읽을 때 채운다. 시드에 같은 id가 있으면 그 분류와 묶음을,
  없으면 `미분류`/`기타`를 쓰고 방식은 줄 모양으로 알아낸다. 다음 저장 때 새 모양으로 다시 쓴다.
- **화면**
  - 관리 페이지 왼쪽은 `분류 > 묶음 > 오라클` 순서다(일반·장소·인물·기타 순, 그 밖은 이름순).
    이름으로 거를 수 있다. 오른쪽은 고른 오라클의 상세와 편집 창이고, `새 오라클`은 빈 한 칸씩 표로 시작한다.
  - 지우기는 상세에서 한 번 더 확인한다. 되돌릴 수 없기 때문이다.
  - 세션 패널은 검색·굴리기·매크로 등록/해제와 `오라클 관리` 링크만 남는다.

## 작업하며 배운 것

- **siheom의 query·action 이름은 패키지 안이 아니라 공개 문서에서 확인한다.** 타입 정의를 뒤지다가
  `query.link`가 있는지, `assertions.href`가 있는지 확인하느라 시간을 버렸다. `.claude/skills/siheom-frontend-test/`
  의 `SKILL.md`와 `API.md`를 먼저 읽는다(`AGENTS.md`에 적어 두었다).
- **테스트는 기능과 함께 쓴다.** 화면을 다 만든 뒤에 테스트를 몰아 붙이면, 그 사이에 어긋난 설계를
  나중에야 발견한다. 이번에도 `1번째 줄 시작`이 spinbutton이라 값 비교가 숫자/글자로 갈리는 것을 늦게 알았다.
- **`<input list="...">`는 textbox가 아니라 combobox다.** 분류·묶음 입력은 `query.combobox`로 찾는다.
- **`actions.fill`에 줄바꿈이 있으면 브라우저 모드에서 5초 안에 끝나지 않는다.** 글자마다 한 번씩 다시 그리는
  탓인데, 대신 `{Enter}`를 쓰고 입력을 짧게 유지한다. 긴 표는 도메인 테스트(`parseOracleRows`)가 맡는다.
- **브라우저 모드는 파일을 여럿 동시에 불러오면 몇 개를 받지 못해 죽는다.** "Failed to import test file"이
  파일마다 돌아가며 났다. `component` 프로젝트에 `fileParallelism: false`를 두어 한 파일씩 돌린다.
- **시드는 파일이 없을 때만 쓰이므로, 이미 돌린 앱은 분류가 붙지 않는다.** 읽을 때 시드에서 채우도록 고쳤다.
  실제로 실행 중인 서버가 19개를 모두 `미분류 > 기타`로 돌려주는 것을 보고 찾았다.
