# TICKET-00006 작업 계획 (끝나면 지운다)

## 체크리스트 (TDD 순서)

- [ ] 제출 직후 새 이벤트가 `pending`, 저장이 끝나면 `committed` (entries에 `status`)
- [ ] 저장이 실패하면 그 이벤트가 `failed`, 이미 커밋된 이벤트는 그대로
- [ ] 연속 세 번 제출하면 순서대로 저장된다 (앞이 실패하면 뒤는 저장하지 않고 `failed`)
- [ ] `submit`은 저장을 기다리지 않고 곧바로 돌아온다 (입력이 바로 비워진다)
- [ ] 충돌: 다른 탭이 먼저 썼으면 다시 불러오고, 버려진 제출의 글이 `restored`로 돌아온다
- [ ] 실패한 뒤 다음 제출은 서버 상태로 다시 불러온 뒤 적용한다
- [ ] 입력창이 `restored`를 받으면 글과 화자를 채운다
- [ ] 세션 로그 스토리에 pending/failed 섞인 경우, "저장 중"/"실패" 표시
- [ ] 파일 로그: 깨진 마지막 줄(줄바꿈 있어도) 무시, 이어 쓰기, 중간 줄이 깨지면 오류

## 핵심 결정

- **pending/failed 표현.** 컨트롤러는 "저장된 이벤트"와 "저장 전 묶음"(`unsaved`: 한 번의 mutation이 만든 이벤트들 + 상태 `pending|failed` + 입력 글)을 따로 든다.
  화면 이벤트 목록 = 저장된 것 + 저장 전 묶음. `toLogEntries(events, statuses)`가 eventId별 상태를 받아 `LogEntry.status`를 채우고, 없으면 `committed`다.
  표시용 컴포넌트는 `status`만 본다.
- **순차 커밋.** mutation을 바로 적용하고 곧바로 `repository.commit`을 부른다(ventyd가 큐를 그 자리에서 비우므로 묶음마다 expectedVersion이 정확하다).
  어댑터가 쓰는 저장소를 컨트롤러가 감싸 `append`를 promise 꼬리(tail)에 줄 세운다. 저장 전 묶음의 등록도 이 `append`가 한다(ventyd는 commit 안에서 동기적으로 어댑터를 부른다).
- **실패한 큐.** 한 묶음이 충돌 아닌 이유로 실패하면 이후 묶음은 저장하지 않고 모두 `failed`로 둔다(앞이 없으니 버전이 이어지지 않는다). 자동 재시도 없음.
  다음 제출은 큐가 끝나기를 기다린 뒤 서버에서 다시 불러와(실패한 것은 사라진다) 새 제출을 적용한다. CONTEXT.md에 남긴다.
- **충돌.** 저장 중 `VersionConflictError`가 나면 저장 전 묶음을 모두 버리고 로그를 다시 읽는다. 버려진 묶음의 입력 글은 `view.restored[side] = { key, as, text }`로 돌아온다.
  `key`는 충돌마다 늘어 입력창의 effect가 한 번만 채운다. 다시 읽는 동안 들어온 제출은 끝나기를 기다린다.
  `submit`은 저장을 기다리지 않으므로(곧바로 `undefined`) 충돌은 반환값이 아니라 `restored`로 알린다.
- **입력창.** `restored`를 받으면 `SpeakerFallback`처럼 폼 안의 작은 컴포넌트가 글이 비어 있을 때만 글과 화자를 채운다(그새 새로 쓴 글을 덮지 않는다).
  컨테이너는 `restored={view.restored[side]}`만 넘긴다(분기 없음).
- **표시.** 저장 중은 말풍선을 흐리게(opacity), 시각 자리에 작은 "저장 중". 실패는 말풍선에 점선 테두리와 작은 빨간 "실패". 모두 작고 눈에 띄되 로그를 지배하지 않게.
- **가짜.** `event-log-store.fake.ts`: 메모리 저장소를 감싸 `hold`/`releaseNext`(저장을 손으로 풀기), `failNext(error)`, `otherTab`(같은 메모리에 직접 쓰기)를 준다.
- **깨진 마지막 줄.** 이미 있는 "줄바꿈 없는 끝 조각" 처리에 더해, 줄바꿈으로 끝나도 마지막 줄이 JSON이 아니면 깨진 줄로 본다(경고 후 무시, 다음 append가 잘라 냄). 중간 줄이 깨지면 오류.
- **열어 둔 것.** 캐릭터 추가 입력은 충돌 때 되돌려 주지 않는다(재입력). 충돌 안내 문구는 화면에 따로 두지 않는다.
